# Simple Calculator 🧮📱

A clean, lightweight, and fast mobile calculator application engineered to handle standard arithmetic expressions seamlessly.

## ✨ Features
- **Core Arithmetic:** Supports addition, subtraction, multiplication, and division.
- **Expression Parser:** Evaluates mathematical strings efficiently.
- **Clutter-Free UI:** Ergonomic mobile keypad layout.

## 🛠️ Tech Stack
- **Language:** Java
- **Framework:** Android Studio / Android SDK
